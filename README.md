# Z-Hold

![capa jogo](img\capa_z_hold.jpeg)

Z-Hold é um jogo de defesa por ondas em pixel art. Proteja seu posto contra zumbis que atacam pela frente e por trás: alterne a câmera, colete moedas e melhore armas e defesas.

## Requisitos

- Unity **6000.3.25f1**
- Módulo **WebGL Build Support** da Unity, caso queira gerar a versão para navegador

## Como abrir e jogar na Unity

1. No Unity Hub, escolha **Add project from disk** e selecione a pasta deste projeto.
2. Abra o projeto com Unity 6000.3.25f1 e aguarde a importação.
3. Abra `Assets/_Project/Scenes/Boot.unity` e pressione **Play**.

## Controles

| Ação | Controle |
| --- | --- |
| Mirar e disparar | Mouse e botão esquerdo |
| Coletar moedas | Mire na moeda e use o botão direito |
| Recarregar | R |
| Trocar entre frente e costas | Q, E, Tab ou rodinha do mouse |
| Usar habilidade especial | Espaço |
| Pausar | Esc |
| Avançar da loja | Enter |
